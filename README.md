# Rajesh K. Jat - AI Engineer Portfolio

**Building Real-Time Intelligence for the Edge**

A cutting-edge portfolio website showcasing expertise in Generative AI, Computer Vision, and Edge ML systems. Built with modern web technologies and featuring glassmorphism design with 3D animations.

## 🚀 About

AI Engineer with 2+ years of experience building real-world AI systems across:
- **Generative AI & LLM Systems**: LangChain, LlamaIndex, vLLM, LLaMA, Mistral, CrewAI
- **Computer Vision & Analytics**: YOLOv8 with OBB, trajectory estimation, satellite image processing
- **Edge ML & Backend**: FastAPI, Docker, NVIDIA Jetson, TensorRT optimization

## 🛠️ Tech Stack

### Frontend
- **Framework**: React 18 + TypeScript
- **3D Graphics**: Three.js, React Three Fiber
- **Animations**: Framer Motion
- **Styling**: Tailwind CSS with custom glassmorphism effects
- **Build Tool**: Vite

### Design Features
- 🎨 Professional black-and-white theme with accent color (#007ACC)
- 🌟 Interactive 3D background with floating elements
- 📱 Fully responsive, mobile-first design
- ⚡ Optimized performance and smooth animations
- 🔧 TypeScript for type safety and better development experience

## 🚀 Getting Started

1. **Clone the repository**:
```bash
git clone https://github.com/Rjaat/ai-engineer-portfolio.git
cd ai-engineer-portfolio
```

2. **Install dependencies**:
```bash
npm install
```

3. **Start development server**:
```bash
npm run dev
```

4. **Open in browser**: [http://localhost:5173](http://localhost:5173)

## 📦 Build & Deploy

### Build for production:
```bash
npm run build
```

### Deploy to GitHub Pages:
```bash
npm run deploy
```
